# AgriMind AI - Advanced Smart Farming

AgriMind AI is a comprehensive, data-driven agricultural ecosystem designed to empower Indian farmers. It serves as a unified digital platform providing hyper-local insights, real-time marketplaces, AI diagnostics, and equipment rental hubs directly in the hands of the farming community.

## Problem Statement

Agriculture today faces multiple challenges:

*  🌱 Lack of modern farming knowledge among new generation
*  🌦 Unpredictable weather affecting crop yield
*  🧪 Poor understanding of soil and crop requirements
*  🐛 Late detection of crop diseases
*  📉 No real-time access to mandi prices and government schemes
*  🤝 Lack of collaboration among farmers
## 🌟 Key Features

*   **Community AI Crop Doctor**: Instant plant disease detection. Upload a photo of a damaged leaf, and the AI will analyze it against 10,000+ diseases to provide precise, organic treatment solutions.
*   **Smart Fertilizer Calculator**: Stop wasting money on excess chemicals. Input your crop type and land area to calculate the exact NPK (Nitrogen, Phosphorus, Potassium) requirements for your soil.
*   **Equipment Rentals (Uber for Tractors)**: Rent heavy machinery from local farmers by the hour. A community-driven queue system ensures transparent booking and availability.
*   **Live Market Prices**: Search for any crop to see real-time wholesale Mandi prices across India, helping farmers make informed selling decisions.
*   **Direct Farmer Marketplace**: Zero mediators. Sell crops directly to bulk buyers. Integrated directly with WhatsApp for seamless and immediate communication.
*   **Government Schemes & Subsidies**: Discover and apply for eligible government benefits, including PM-KISAN, PMFBY, and Kisan Credit Card.
*   **Hyper-Local Insights**: Location-aware features detect your current region to provide real-time weather forecasting and localized data.
*   **Multilingual Support**: Fully accessible in English and Hindi to ensure ease of use for a wider demographic.

## 🚀 Getting Started

Since AgriMind AI is built with a focus on simplicity and offline-first capabilities using native web technologies (HTML, CSS, JavaScript) and `localStorage`, no complex backend setup is required.

1.  Clone or download this repository.
2.  Open `index.html` in your modern web browser.
3.  Allow location permissions when prompted to enable hyper-local features (Weather & Prices).

## 🛠️ Technology Stack

*   **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
*   **State Management**: Browser `localStorage` for persistent marketplace listings, equipment rentals, and user preferences.
*   **Design**: Custom modern UI with glassmorphism, dynamic animations, and responsive layouts.
*   **Integrations**: 
    *   PlantNet API (for Crop & Disease Identification)
    *   Geolocation API (for local weather and mandi prices)
    *   WhatsApp Protocol (for direct farmer-buyer contact)

## 📱 User Experience Focus

The platform is designed to be highly responsive, lightweight, and visually premium, addressing the needs of rural users without compromising on modern web aesthetics. Features include dynamic data tickers, parallax scrolling, micro-animations, and a fully functional offline-capable architecture.

## 🌾 AgriMind AI – Summary

AgriMind AI is an AI-powered smart farming platform that helps farmers make better decisions using data, artificial intelligence, and community support. It combines features like crop recommendation, disease detection, irrigation planning, weather insights, and mandi price tracking in one mobile application.

The platform also includes a social community, where farmers can share knowledge, experiences, and learn from each other. By integrating AI models and real-time data, AgriMind AI aims to increase productivity, reduce crop losses, and promote modern, data-driven farming practices.
